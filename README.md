## Описание
Приложение «Доска публикаций», демонстрирующее работу с DOM, событиями и асинхронными запросами (fetch, async/await) к REST API JSONPlaceholder.

## Как запустить
1. Распакуйте архив.
2. Откройте файл `index.html` в любом современном веб-браузере (двойной клик по файлу).
3. Дополнительные серверы или сборщики не требуются. Все скрипты выполняются на стороне клиента.

## Результаты проверки (Чек-лист)
1. **Загрузка (GET):** При нажатии кнопки «Загрузить публикации» выполняется запрос, интерфейс показывает статус загрузки. После успешного ответа на странице отображаются 5 записей с заголовками и текстом.
2. **Валидация формы:** Если нажать «Создать публикацию» с пустыми полями или полями, содержащими только пробелы, появляется красное сообщение об ошибке. Запрос (POST) не отправляется.
3. **Создание (POST):** При вводе корректных данных и отправке формы выполняется POST-запрос. Появляется сообщение об успехе с заголовком и ID новой публикации, а сама публикация добавляется в начало списка на странице.
4. **Обработка ошибок:** При временной замене URL GET-запроса на несуществующий адрес (например, `https://jsonplaceholder.typicode.com/postz`) появляется сообщение об ошибке, а кнопка «Загрузить публикации» снова становится активной для повторной попытки.

*Примечание:* JSONPlaceholder является имитацией API. Созданные посты не сохраняются на сервере после обновления страницы.
